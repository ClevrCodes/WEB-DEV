# Pressure Points — The Truth About Student Life

A cinematic one-page frontend experience about student pressure, expectations, comparison, and resilience.

## Run locally

Option 1:
- Open `index.html` directly in a browser.

Option 2:
- From this folder, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Files

- `index.html` — page structure and sections
- `style.css` — cinematic styling and responsive layout
- `script.js` — interactive behavior, intro flow, split slider, and section updates

## Notes

- The site uses vanilla HTML, CSS, and JavaScript for a lightweight, dependency-free build.
- Intro animation is skippable and respects reduced-motion preferences.
- The design is optimized for desktop and mobile screens.
